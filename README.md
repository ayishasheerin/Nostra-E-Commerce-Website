Nostra – E-Commerce Website

About the Project

Nostra is a fashion e-commerce website developed using HTML, CSS, and JavaScript. The website provides a simple and user-friendly interface for exploring fashion products, browsing collections, and contacting the store.

The website is designed to work on both desktop and mobile screens using responsive CSS techniques.

Features

* Home Page: Displays the main navigation bar, promotional banner slider, product sections, and newsletter subscription area.
* Collections Page: Displays fashion products with search functionality and filters.
* Product Search: Allows users to search for products by name and related details.
* Occasion Filters: Filter products by Summer, Party, and Beach.
* Color Filters: Filter products by colors such as Red, Blue, White, and Green.
* Arrival Filters: Filter products by New and Old arrivals.
* Responsive Design: Uses CSS clamp() to adjust font sizes, spacing, and element dimensions according to screen size.
* Navigation Menu: Provides links between the website pages and a slide menu for navigation.
* Image Slider: Allows users to navigate through promotional banners.
* Wishlist Interaction: Allows users to toggle product heart icons.
* Contact Us Page: Includes Name, Email, and Message fields with basic browser validation.
* Newsletter Section: Includes an email input and subscription button.
* Footer: Displays the website name, description, and social media icons.

Technologies Used

* HTML5 – Website structure and content.
* CSS3 – Styling, layout, and responsive design.
* JavaScript – Search, product filtering, banner slider, slide menu, and wishlist interactions.
* Font Awesome – Icons used in the interface.

Project Pages
